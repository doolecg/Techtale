# Techtale

Techtale is a Hytale mod about tech, machines, power and ore processing, in the style of Mekanism.

## Get started

Needs Java and a Hytale server 0.6.8. The mod is one server plugin jar that is also an asset pack.

```
gradlew build
```

That's it. The jar is in `build/libs`.

## Common commands

```
gradlew test        # unit tests
gradlew smokeTest   # boot a real server with the mod
gradlew runServer   # start a dev server
```

Planned work is listed in `docs/plan.md`.
