# Techtale plan

A Hytale mod that plays like Mekanism: ores, multi-step ore processing, machines that run on power, cables, pipes, tanks, and later multiblocks and gear.

Target: Hytale **0.6.8** (Update 6, release patchline), server jar `com.hypixel.hytale:Server:0.6.8` from `https://maven.hytale.com/release`, Java 25 bytecode. Hytale modding = one server plugin jar (Java) that is also an asset pack (`Server/`, `Common/` at the jar root). No client code: every visual is data (block JSON, `.blockymodel`, textures, `.ui` pages).

## How it fits Hytale

| Mekanism idea | Hytale mechanism |
|---|---|
| Tile entity | ChunkStore component registered in `setup()`, attached in block JSON `BlockEntity.Components` |
| Ticking | `EntityTickingSystem<ChunkStore>`; machine logic steps at 20 Hz (Mekanism numbers stay per-tick) |
| Network rebuild on place/break | `RefSystem` on the transmitter component (add/remove fires for every way a block appears/disappears) |
| Machine GUI | `InteractiveCustomUIPage` + `.ui` file in `Common/UI/Custom/Pages/Techtale/`, item slots as `ItemGrid`s, refreshed by a player ticking system |
| Right-click to open | Custom `Interaction` type registered on `Interaction.CODEC`, block JSON `Interactions.Use` |
| Active/idle model | Block `State.Definitions` variants, switched with `world.setBlockInteractionState` (keeps component data) |
| Cable shapes | 64 state variants (one per 6-bit connection mask) per transmitter, generated by `tools/`; Java picks the state |
| Ores | Ore blocks on vanilla `Ore_Large.blockymodel` with our textures; legacy V1 worldgen (`Server/World/Default/Ores/...`) |
| Machine recipes | Our own JSON under `techtale/recipes/` in the jar, loaded with the server's bundled Gson |
| Crafting the machines | Vanilla workbench recipes (`BenchRequirement` Crafting/Workbench) |

Machines only tick in chunks near a player (Hytale's hot sections). An Anchor-upgrade style chunk keeper comes later.

### Materials Hytale lacks
- Carbon: `Ingredient_Charcoal` (10 carbon), enriched carbon (80).
- Redstone's role: copper. Enriched Copper replaces Enriched Redstone (infused alloy, circuits).
- Diamond: `Rock_Gem_Diamond`.
- Refined Obsidian: volcanic rock dust (`Rock_Volcanic`) infused with diamond.
- Glowstone (later): `Ingredient_Motes_Light`. Brine: `Ingredient_Salt`.

### Ids
All our ids start with `Techtale_` (e.g. `Techtale_Ingot_Osmium`, `Techtale_Ore_Osmium_Stone`, `Techtale_Enrichment_Chamber`). Display names come from `Server/Languages/en-US/server.lang` (`items.<Id>.name`).

## Code layout (`com.doolecg.techtale`)
- `core/` pure Java, no Hytale imports, unit tested: `Direction`, `energy/EnergyBuffer`, `machine/MachineDefinition`+`Machines` registry, `machine/UpgradeMath`, `recipe/*` (recipe types, JSON loading), `machine/ProcessLogic`, `network/TransmitterGraph`, `network/EnergyNetwork`.
- `hytale/` the adapter: components, systems, per-world network manager, interactions, UI pages, commands.
- `tools/` Python generators for repetitive assets (item/block JSON, lang, textures, icons, cable state models). Generated files are committed.

## Numbers (Mekanism 10.x defaults)
- Energy unit: Joules (J), `long`. Logic tick = 1/20 s.
- Universal cable J/t: Basic 8,000; Advanced 128,000; Elite 1,024,000; Ultimate 8,192,000.
- Energy cube capacity / output J/t: Basic 4 MJ / 4,000; Advanced 16 MJ / 16,000; Elite 64 MJ / 64,000; Ultimate 256 MJ / 256,000.
- Basic machines: 20,000 J buffer, 50 J/t, 200 ticks per operation (Osmium Compressor 100 J/t).
- Upgrades (max 8 each): ticks = base * 10^(-speed/8); J/t = base * 10^((2*speed - energy)/8); capacity = base * 10^(energy/8).
- Heat Generator: 200 J/t from fuel (charcoal 10 s per item etc.), 160,000 J buffer. Solar Generator: 50 J/t in daylight, 96,000 J buffer.

## Phases

### Phase 1: foundation (this milestone)
1. Build, run configs, smoke boot on the real server (done: plugin loads on 0.6.8).
2. Core logic + tests: energy buffers, upgrade math, recipes, processing, transmitter graph, energy network.
3. Content assets: ores (Osmium, Tin, Lead, Uranium, Fluorite in Stone/Basalt/Sandstone/Shale/Slate hosts), raw ores, ingots (osmium, tin, lead, uranium, steel, bronze, refined obsidian), dusts and dirty dusts (all Mekanism metals + vanilla Hytale metals), clumps/shards/crystals (for later phases), alloys (infused, reinforced, atomic), control circuits (4 tiers), steel casing, enriched materials, upgrades (speed, energy), Configurator.
4. Ore worldgen in the default (V1) generator; verified by a debug ore-count command.
5. Hytale integration: machine component + tick, energy cube, generators, cable component + network manager, use-interaction, machine UI page with item slots, energy and progress bars, active state visuals.
6. Machines: Enrichment Chamber, Crusher, Energized Smelter, Metallurgic Infuser, Osmium Compressor, Combiner. Generators: Heat, Solar. Energy Cubes (4 tiers). Universal Cables (4 tiers). Double ore processing works end to end.
7. Recipes for every Phase 1 block/item on the vanilla Workbench.

### Phase 2: fluids and chemicals
Mechanical pipes, pressurized tubes, fluid and chemical tanks, electric pump, electrolytic separator, chemical oxidizer/infuser, rotary condensentrator, purification chamber (x3), chemical injection chamber (x4), dissolution chamber + washer + crystallizer (x5), gas-burning, bio and wind generators, pressurized reaction chamber.

### Phase 3: logistics and factories
Side configuration + auto-eject, logistical transporters (4 tiers), logistical sorter, bins, factories (basic to ultimate), tier installers, personal chest, chargepad, teleporter, digital miner, chunk anchor.

### Phase 4: multiblocks
Dynamic tank, induction matrix, thermal evaporation plant, boiler, industrial turbine, fission reactor, fusion reactor, SPS.

### Phase 5: gear
Jetpack, atomic disassembler, free runners, scuba gear, Meka-Tool, MekaSuit, flamethrower, portable teleporter.

## Verification
- `gradlew test`: core logic.
- `gradlew smokeTest`: boots the real 0.6.8 server with the jar, stops it, fails on any error/warning that mentions our pack or package.
- In game: `gradlew deployClient` copies the jar to `%APPDATA%/Hytale/UserData/Mods`, then a creative singleplayer world; `gradlew runServer` for a dedicated dev server.
